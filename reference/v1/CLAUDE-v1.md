# 割烹 舞ぅ 公式サイト 制作指示書（Claude Code 用）

## 0. ゴール

| 項目 | 内容 |
|---|---|
| 目的 | 長崎の割烹「舞ぅ」の集客用公式サイトを作る |
| 最重要 | **予約のしやすさ**と**空き状況が分かること**。現状の予約は電話とInstagram DMのみ |
| 店側の運用 | **更新作業はほぼなし**。空き状況は予約データから自動で計算する |
| 開発サーバー | **http://localhost:3100**（`npm run dev`） |
| 技術 | 静的な HTML / CSS / Vanilla JS ＋ Vite（開発サーバーのみ）。フレームワークは使わない |
| 予約の裏側 | Google スプレッドシート ＋ Google Apps Script（GAS）＋ Resend（確認メール） |

---

## 1. 最初にやること

```bash
npm install
npm run dev     # → http://localhost:3100 で表示されること
```

- ポートは **3100 固定**（`vite.config.js` と `package.json` で `--strictPort` を指定済み）
- 3100 が使用中ならエラーで止まる。その場合は使用中のプロセスを止める（別のポートに逃がさない）

## 7. 空き状況カレンダーと予約フォーム（最重要）

試作の `reference/prototype-index.html` のスクリプトを `js/reserve.js` に移して、以下を変更する。

### 仕様

| 項目 | 内容 |
|---|---|
| 表示 | 月のカレンダー（今月＋翌月、前月・翌月の切り替え）。各日に ○ 空きあり／△ 残りわずか／× 満席／休 定休日 |
| 部 | **昼と夜の2部制**。カレンダーの上に「昼／夜」の切り替えを置き、日付のマスは夜の空きで表示（昼を選ぶと昼の空きに切り替わる） |
| 時間枠 | 昼 11:00 / 11:30 / 12:00 / 12:30 / 13:00、夜 18:00 / 18:30 / 19:00 / 19:30 / 20:00 |
| 人数 | 1〜4名。5名以上を選ぶと「お電話でご予約ください」と電話ボタンを表示 |
| 流れ | ①日付 → ②部・時間 → ③人数・コース・お名前・電話・メール・アレルギー/ご要望 → ④確認 → ⑤完了（予約番号を表示） |
| 表示形式 | モーダル（スマホは下から出るシート）。進み具合を4段のバーで表示 |
| 送信 | `fetch(GAS_URL, {method:'POST', headers:{'Content-Type':'text/plain;charset=utf-8'}, body: JSON})`（preflight を避けるため text/plain） |
| 失敗時 | 「満席になりました」などのエラーを表示し、電話番号を案内。カレンダーを再読み込みする |
| デモモード | `GAS_URL` が空なら、ダミーデータで最後まで動く（「デモ表示です」と明示） |
| 同意 | 送信ボタンの上に「プライバシーポリシーに同意のうえ送信」のチェックボックス |
| 規定の表示 | 確認画面にキャンセル規定・5名以上は電話・電話の受付時間を表示 |

### js/config.js
```js
export const CONFIG = {
  GAS_URL: "",                       // GASのウェブアプリURL（空ならデモ）
  SHOP_NAME: "割烹 舞ぅ",
  TEL: "095-823-8510",
  TEL_HOURS: "10:00–22:00（日曜休）",   // TODO 要確認

  MONTHS_AHEAD: 2,
  NEWS: [ { date: "2026-11-01", text: "Webからのご予約を始めました" } ],
};
```

## 8. GAS（gas/Code.gs）の修正

同梱の `Code.gs` は夜だけの1部制。以下のように修正する。

| 修正点 | 内容 |
|---|---|
| 2部制 | 「設定」シートに `昼の時間枠` `夜の時間枠` `昼の滞在時間(分)` `夜の滞在時間(分)` を追加。API の返り値を `days[date] = { status, lunch:{status, slots}, dinner:{status, slots} }` にする |
| 初期値 | 席数 17、1組の最大人数 4、定休曜日「日」、受付締切 3時間前、受付期間 60日 |
| 予約シート | 「部」の列（昼/夜）を追加 |
| 席の内訳 | 当面は合計17席で計算する（内訳が分かれば卓単位の計算に変更する。TODO コメントを残す） |
| メール | お客様には Resend（`RESEND_API_KEY` はスクリプトプロパティから読む。**キーをコードに書かない**）、店には Gmail（MailApp）で通知 |
| 排他 | `LockService` で同時予約を防ぐ（実装済み） |
