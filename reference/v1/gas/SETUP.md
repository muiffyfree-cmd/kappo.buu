# 予約システム 設定手順（所要 約20分）

| # | 作業 | 詳細 |
|---|---|---|
| 1 | スプレッドシートを作る | 店のGoogleアカウントで新規作成（名前は「舞ぅ 予約台帳」など） |
| 2 | GASを開く | メニューの「拡張機能」→「Apps Script」 |
| 3 | コードを貼る | `Code.gs` の中身を全部貼り付けて保存 |
| 4 | 初期設定 | 関数 `setup` を選んで「実行」→ 権限を許可。「設定」「予約」「臨時休業日」の3シートができる |
| 5 | 設定を記入 | 「設定」シートを確認する（初期値：席数17・1組の最大4名・昼／夜の時間枠・定休曜日「日」）。店のメールと送信元を書き換える |
| 6 | Resendの準備 | 独自ドメインを認証 → APIキーを「Sending access」で作成 |
| 7 | APIキーを登録 | GASの「プロジェクトの設定」→「スクリプト プロパティ」に `RESEND_API_KEY` ＝ キー |
| 8 | 公開 | 「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」／実行ユーザー「自分」／アクセス「全員」 |
| 9 | URLをサイトに設定 | 発行されたURLを `js/config.js` の `GAS_URL: ""` に貼る |
| 10 | テスト | 自分のメールで1件予約 → 確認メールと店への通知が届けばOK → 「予約」シートの該当行を「キャンセル」に |

## お店がやること（これだけ）

| 場面 | 作業 |
|---|---|
| 電話・DMで予約を受けた | 「予約」シートに1行追加（日付・部（昼/夜）・時間・人数・名前・経路＝電話）。部を空欄にすると時間から自動で判断（16時より前は昼） |
| キャンセルの連絡 | 「状態」を「キャンセル」に変更 → 空きが自動で戻る |
| 臨時休業 | 「臨時休業日」シートに日付を追加 |

※ Googleスプレッドシートのスマホアプリから操作できます。
※ `Code.gs` を修正したときは「デプロイを管理」→ 編集 →「新バージョン」で再デプロイが必要です。
